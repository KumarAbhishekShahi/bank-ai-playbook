# AI Use-Case Intake (2 pages max)
1. Use case in business language; the DECISION it changes.
2. Value unit (bps loss, hours, cycle time, revenue) + rough size.
3. Data touched (classes, PII?, residency) + lawful purpose.
4. People affected (customers? employees?) + failure cost in plain words.
5. Autonomy: informs / drafts / acts-with-approval / acts-alone.
6. Why now. 7. Sponsor (P&L owner) + builder team.
→ CoE returns: tier, required controls, register ID — within 5 working days.
