# Risk Tiering Rubric
Score materiality (money moved / customers affected / regulatory exposure: 0-3 each)
and autonomy (informs 0 · drafts 1 · acts w/ approval 2 · acts alone 3).
**T1** mat≥6 or autonomy 3: independent validation (or GenAI eval-gate equivalent), HITL, monitoring w/ thresholds, incident drill, binder.
**T2** mat 3-5: eval gates, monitoring, model card, annual review.
**T3** else: register entry, model card lite, acceptable-use compliance.
GenAI/agentic additions per tier: golden set + grounded-rate gate; tool permission map; blast-radius note (T1).
